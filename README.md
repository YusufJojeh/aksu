# Dental Operations & Treatment Plan Generator

A production React application for Aksu Dental and MB Dental. Authenticated sales staff create clinic-specific five-page treatment plans; the exact finalized PDF and an immutable data snapshot are archived privately. Administrators manage employees, communication numbers, historical reports, and operational analytics.

## Local development

```bash
npm install
npm run dev
npm run lint
npm test
npm run build
```

Copy `.env.example` to `.env.local` and supply a Supabase project URL and public anon key. The app fails closed when those values are absent. The test server alone may set `VITE_E2E_AUTH_BYPASS=1`; production builds never set it.

## Architecture

- `src/auth/`: Supabase session and server-backed employee profile state.
- `src/clinics/registry.ts`: clinic capabilities, locales, currencies, and template metadata.
- `src/domain/`: the discriminated Aksu/MB report model, validation, and minor-unit totals.
- `src/pdf/`: clinic-specific coordinate profiles and browser-side PDF generation.
- `src/lib/operations.ts`: private archive upload, finalization RPCs, downloads, and admin operations.
- `src/components/sales/`: create, report history, and profile workflows.
- `src/components/admin/`: analytics, employees, communication numbers, and report archive.
- `supabase/migrations/`: schema, immutable-history triggers, RPC validation, and RLS.
- `api/admin/invite-employee.ts`: admin-only employee invitation (Vercel serverless function); the service-role key remains server-side.

PDF generation remains local to the browser. On finalization, the generated bytes are uploaded to the private `report-pdfs` bucket, hashed, and committed through a security-definer RPC that independently validates identity, payload metadata, totals, and storage ownership. Downloads always use the archived bytes.

## Clinics and templates

Aksu supports its existing locale behavior and seven treatment rows. MB Dental supports only English, French, German, and Arabic, requires Patient ID, has six rows per visit, and has no discount concept.

The current MB French and Arabic templates are clean derivatives of the latest supplied real reports (`SERGIO ALMEIDO.pdf` and `السيد خالد..pdf`). The source references are never modified. Coordinates were measured from those reports; static pages and artwork remain intact. English and German continue to use their supplied clinic templates.

The development-only coordinate mapper is available at `/dev/pdf-mapper` under `npm run dev` and is excluded from production routing. See `PDF_FIELD_MAP.md` and `LOCALIZATION.md` for field and RTL details.

## Deployment

Apply the Supabase migration, bootstrap the first administrator, set the Vercel environment variables, and deploy. `api/**` (including the invite endpoint) deploys automatically alongside `dist/` as Vercel serverless functions. See `DEPLOYMENT.md`.
