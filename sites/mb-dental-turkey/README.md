# MB Dental Turkey — Client Website Showcase

Independent bilingual English/Arabic dental marketing site, created from the visual direction and content research of the Lovable project.

- Full home, treatment catalog + five details, journey, contact, privacy, brand identity guide
- Mobile-first responsive UI, accessible interactions, reduced-motion support
- WhatsApp inquiry with client-side validation and ad attribution preservation
- Only official clinic contact information and treatment categories; no invented outcomes or testimonials
- Static site: deploy with Vercel and rewrite to /index.html for deep links

Production source copied to this branch. The existing main branch is unchanged.
